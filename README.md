# ToolTomato — Phase 1 Files

Ye Phase 1 (website foundation) ke saare files hain — homepage, about, contact, 9 legal/compliance pages, 404, favicon, aur styling/JS.

## GitHub par live karne ke steps

1. **GitHub.com** par free account banao (agar nahi hai).
2. Naya repository banao:
   - Repository name: `tooltomato`
   - Public rakhna
   - "Add a README" ko UNCHECK rakhna (hum apna README already la rahe hain)
3. Repo khulne ke baad **"Add file" → "Upload files"** par click karo.
4. Is folder (`tooltomato`) ke andar ka **poora content** (index.html, about.html, css folder, js folder, sab kuch) drag-and-drop karke upload karo — folder structure preserve rahega.
5. Neeche "Commit changes" button dabao.
6. Ab **Settings → Pages** me jao:
   - "Branch" me `main` select karo, folder `/ (root)` rakho, Save karo.
7. 1-2 minute me aapki site live ho jaayegi is URL par:
   `https://<yourusername>.github.io/tooltomato/`

## Baad me karne wale kaam (abhi ke liye placeholder hain)

- `contact.html` aur `dmca.html` me apna real email daalo (`hello@tooltomato.com` ki jagah)
- Sabhi legal pages me `[Add Date]` ko real date se replace karo
- `terms.html` me `[Your Country/State]` bharo
- Custom domain (`.com`) baad me buy karke GitHub Pages se jod sakte ho (optional, paid)
